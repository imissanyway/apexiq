ApexIQ v4.9.9.12 Stability Fix Report
=====================================

Fixes applied after reviewing the uploaded screen recording:
- Rebuilt the search form with one final stable owner (v49912), preventing old stacked patches from replacing/twitching the input/button during load.
- Disabled automatic full profile search on page boot; Search only runs when clicked/submitted.
- Search button now stays Search on load and only switches to Searching… during an explicit request.
- Ranked loader now has a working Retry Ranked path with /api/ranked-fast first and /api/ranked fallback.
- Ranked display uses cached data if live retry fails, instead of leaving a dead retry button.
- Legend cards are rendered from clean deduped rows, with max 4 trusted stat chips and no repeated badge spam.
- Profile stat cards were tightened to stop overflow/cramped card layout.
- Badge Case now displays deduped legend-specific badge rows only.

Package notes:
- This build keeps all 120 transparent badge PNGs.
- Badge deploy assets remain web-optimized 416x416 to stay under the 26 MB upload limit.
- No source sheets, contact sheets, old backup HTML files, or embedded single-file HTML are included.
