4. Upload index.html to GitHub Pages.
5. Open https://imissanyway.github.io/apexiq/?v=49989&admin=1
6. Login with:
   email: coyemicthell@gmail.com
   secret: the value you set for APEXIQ_ADMIN_SECRET
