ApexIQ v4.9.9.29 Meta Force Restore

Built from v4.9.9.28 readable stats restore.

Problem fixed:
- Meta board could still render blank/loading because the endpoint sometimes returns no usable pick-rate rows or a 0-only fallback roster.
- Older meta renderers could repaint the panel after a newer render.

Fix:
- Adds a final meta-only renderer that force-renders the meta panels every 900ms.
- Deep-parses many possible /api/meta response shapes: legends, meta, pickrates, pickRates, rows, data, items, result, payload.
- If live ALS omits rows or returns a 0-only roster, it shows the saved ALS visible snapshot instead of a blank panel.
- Shows pick rate, trend, average rank, and average level.
- Worker fallbackPickratesMeta now returns useful visible snapshot rows before the rest of the roster.
- Does not touch the v4.9.9.24/v4.9.9.28 badge parser.
- Does not touch the readable stat restore CSS except for meta-only styles.

Validation:
- HTML JavaScript syntax check passed.
- Worker syntax check passed.
